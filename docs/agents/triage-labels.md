# Triage Labels

The five canonical triage roles, each label string equal to its name:

| Label | Role |
|-------|------|
| `needs-triage` | Newly arrived, not yet assessed |
| `needs-info` | Blocked waiting on the reporter or external input |
| `ready-for-agent` | Assessed and ready for an agent to work |
| `ready-for-human` | Assessed and needs a human decision or action |
| `wontfix` | Deliberately not doing this |

Apply these labels as-is; do not create duplicates.
