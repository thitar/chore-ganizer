# Issue Tracker: GitHub

Issues for this repo live in **GitHub Issues** for `thitar/chore-ganizer`.

- Create issues with: `gh issue create`
- List/open issues with: `gh issue list`, `gh issue view <number>`
- The repo remote is `git@github.com:thitar/chore-ganizer.git`

## PRs as a request surface

`off` — triage skills do not treat pull requests as incoming work items. Flip to `on`
if you want external PRs to appear in the triage queue.
